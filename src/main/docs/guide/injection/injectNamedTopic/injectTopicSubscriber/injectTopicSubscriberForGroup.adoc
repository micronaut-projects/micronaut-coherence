A `Subscriber` can belong to a subscriber group. When injecting a `Subscriber` it is possible to specify the subscriber group that it belongs to by adding the link:{api}/io/micronaut/coherence/annotation/SubscriberGroup.html[@SubscriberGroup] annotation.

For example, both of the code snippets below inject a `Subscriber` that belongs to the `accounts` subscriber group:
